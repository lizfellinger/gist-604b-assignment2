Overview  
This repository showcases the completion of 10 beginner-level QGIS tutorials. Each tutorial demonstrates a practical application of QGIS. The completed exercises highlight the ability to work with vector and raster data, perform terrain analysis, create cartographic outputs, and apply appropriate data projections and symbology. 
GIS skills developed include vector and raster analysis, terrain analysis, cartographic design, and data visualization through the application of appropriate symbology. Additional skills included working with coordinate reference systems and map projections. Also, the organization and preparation of spatial datasets for analysis was practiced. 

Software Environment  
QGIS Desktop Version 3.44.15 and Microsoft Windows used for all tutorials.   
Google Earth Pro Required for Working with Terrain Data Tutorial.

Reflection  
Through hands-on practice, I developed a better understanding of QGIS's overall layout and its similarities between ArcGIS Pro. For example, the map-making process. While very different between the two applications, I gained a better understanding of how to add and arrange map elements. The biggest challenge was navigating differences between the tutorial instructions and newer software versions. Especially when working with data files. Many tutorials did not require extracting zipped files, but doing so was necessary on my operating system to prevent data-loading issues and processing errors. Troubleshooting these issues strengthened my problem-solving skills and reinforced the importance of properly preparing spatial datasets. I plan to continue applying these skills throughout my graduate education while expanding my GIS portfolio and developing proficiency in additional GIS software.
